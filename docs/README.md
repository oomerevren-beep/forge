### Workflows

- **Single developer:** `forge add` → `forge list` → `forge update`
- **Team:** `forge.toml` → `forge install` → `forge sync`
- **CI/CD:** `forge install --frozen` → `forge audit`
- **Package author:** `forge init` → `forge test` → `forge pack` → `forge publish`
